# Odin 实时深度观察

独立查看原始点云随时间的变化，不依赖 YOLO、持久箱体地图或 map TF。

```bash
cd /home/nvidia/perception_domain_nx
./src/robot_perception/scripts/diagnostics/run_odin_depth_viewer.sh
```

浏览器访问 `http://127.0.0.1:8766`，同一局域网可用 NX 的 IP 替换。
服务默认监听所有网卡，只提供只读图像/点云接口，没有远程相机控制接口。
如果 Odin 驱动已经运行，直接复用；否则启动项目现有驱动。
前台 Ctrl+C 会停止本次启动的驱动，不会停止其他进程原先启动的共享驱动。

## 使用

- RGB 和对齐深度图使用同一数据包中时间差不超过 20 ms 的图像/点云。
  没有匹配的 RGB 时保留实时深度，将 RGB 面板标记为等待配对。
- 选择 A/B/C，点击箱面设置固定区域，读区域内实测点的中位数。
  选在箱面内部，避免区域跨越箱边、遮挡边缘。
- 相对变化以该区域第一组有效观测为基准；可以重置基准，或切换绝对距离。
- 默认显示最近 120 秒，2 Hz。CSV 导出的是这段区域统计历史，不是完整点云录像。
- 暂停只冻结当前浏览器画面；相机仍在工作。断流时不追加重复曲线数据。

## 数据含义

- 原始图显示雷达坐标下 `R = sqrt(x²+y²+z²)`，保留 SDK 的 256×192 行序。
  驱动发布时将 ROS PointCloud2 展平为 49152×1，显示时按 SDK 的列数恢复。
- 对齐图使用设备 Tcl 和内参投影，显示相机光轴方向的 Z。
  同一像素取最近实测点；没有测距的像素留黑，不补洞、不做深度插值。
- 两图颜色使用同一固定量程，超出量程的点显示端点颜色，数值和曲线仍保留原值。
- 置信度阈值只控制显示与选区统计，不修改设备参数。
- P10–P90 是当前区域内深度跨度，可能包含物面倾斜，不能直接当成测距误差。
- 固定像素区域不跟踪物体；相机移动或遮挡后，区域可能观察到另一表面。

## 实测

运行 `node tools/odin1/depth_viewer/verify_live.cjs` 验证实时数据推进、选区中位数与原始值一致、
暂停、CSV、断流提示及恢复、桌面/移动端布局。该脚本不注入假传感器数据，不操作 USB。
报告和截图写入 `runtime/results/odin_depth_viewer/`。
2026-09-10 实测：可视化后端约占一个 CPU 核心的 10%，Odin 驱动约 166%；
百分比以一个核心为 100%，不是整机占用。此数值未包含桌面浏览器。
